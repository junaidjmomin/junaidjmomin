# Evaluation projects

Two small Python projects with synthetic fixtures, passing and failing controls, and reproducible results.

- [Agent replay cases](agent-replay-cases/): cancellation, stale tool results, duplicate retries, source versions and timeouts.
- [RAG order and evidence check](rag-order-evidence-check/): context permutations, answer consistency, citation support and current evidence.

Both use Python 3.10+ and the standard library. Each folder contains its own run instructions, tests, results and limitations. These are offline controls, not measurements of production agents or LLMs. Developed with AI coding assistance.
